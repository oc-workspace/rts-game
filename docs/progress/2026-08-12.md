- 压力编队使用边界内网格排列；测试覆盖数量、确定性、唯一 ID 和战场边界。
- HUD 新增可见/细节单位、simulation/render CPU 时间、超过 33 ms 的长帧和 Three.js draw calls。
- 战术 HUD 保持 10 Hz 更新；舰队列表在压力场景只渲染 10 项和剩余数量摘要，并使用状态签名跳过无变化 DOM 重建。
- 遭遇重载会重置性能窗口和长帧计数；高/低特效仍可随时切换。

### Rendering optimization

- 舰船点光源限制为距镜头最近的 12 个完整细节单位，避免光源数量随舰队规模线性增长。
- 为三类舰船增加单网格远景 LOD；压力场景使用 105 距离阈值，普通遭遇保持 180 距离阈值。
- 被选中舰船无论距离都会恢复完整舰体、材质、贴花、推进器、损伤层和选择环。
- 压力场景将远景舰船按“阵营 × 舰种”合并为最多 6 个 `InstancedMesh` 批次；每帧更新实例矩阵，并维护 `instanceId -> unitId` 映射以保留单击拾取。
- 战斗轨迹和命中/摧毁闪光改为复用对象池，最多保留 256 个 GPU 对象；池满时只省略额外表现，不影响 simulation 伤害和胜负结果。

## Profiling

环境：Codex 内置 Chromium/WebGL，1280×720，高特效，固定 seed `20260810`。浏览器没有暴露可靠的 GPU 型号；FPS 会受到内置浏览器前后台调度影响，因此主要比较 render CPU 提交时间与 draw calls。

### Unoptimized baseline

| 单位 | FPS | Draw calls | Render CPU |
| --- | ---: | ---: | ---: |
| 50 | 59 | 921 | 16.18 ms |
| 100 | 23 | 1,850 | 42.37 ms |
| 200 | 6 | 3,645 | 179.97 ms |

200 单位低特效基线为 14 FPS、3,196 draw calls、70.60 ms render CPU。

### Distant LOD and light budget

| 单位 | FPS | Draw calls | Render CPU | Detail units |
| --- | ---: | ---: | ---: | ---: |
| 50 | 104 | 84 | 5.23 ms | 0 |
| 100 | 37 | 132 | 2.81 ms | 0 |
| 200 | 36 | 228 | 4.89 ms | 0 |

### Instanced distant LOD

| 单位 | FPS | Draw calls | Render CPU | Visible / detail |
| --- | ---: | ---: | ---: | ---: |
| 50 | 52 | 38 | 1.02 ms | 50 / 0 |
| 100 | 51 | 36 | 1.46 ms | 100 / 0 |
| 200 | 55 | 34 | 2.35 ms | 200 / 0 |

不同规模的 draw calls 小幅倒挂来自各 seed 消耗路径生成的中立物和实际出现的舰种批次数不同，不代表单位越多成本越低。实例化前后 FPS 不适合直接横向比较，但 200 单位 render CPU 相对未优化基线下降约 98.7%，draw calls 下降约 99.1%。
