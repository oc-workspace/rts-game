# 开发进度记录

本目录按日期记录每次开发更新，格式参考 [rococo-outreach 的 Progress Log](https://github.com/oc-workspace/rococo-outreach/blob/main/docs/progress/2026-08-09.md)。

## 记录约定

- 文件名使用 YYYY-MM-DD.md。
- 每次更新至少包含：Scope、References、Completed、Current state、Next actions、Security notes。
- Completed 只记录已经完成并验证过的工作，不把计划写成完成项。
- Current state 说明当前可运行/可交付状态和明确限制。
- Next actions 记录下一步最小可执行任务。
- Security notes 不记录 token、密码、授权码、邮箱密码或其他敏感信息。
