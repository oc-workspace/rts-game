# rts-game v0.1.0-rc.1

发布日期：2026-08-12

## 定位

`v0.1.0-rc.1` 是第一版可玩 vertical slice 候选版。它证明 Three.js 路线能够承载固定 seed 随机遭遇、基础舰队控制、三类舰船战斗、战术 HUD、程序化硬科幻视觉和最多 200 单位的可重复压力场景。

本版本不是最终商业版本，也不宣称达到 AAA 最终资产质量。

## 主要内容

- 固定 seed 随机遭遇，支持分享链接、同 seed 重开和随机新局；
- scout、striker、carrier 三类舰船与玩家/敌方阵营；
- 单击、框选、Shift 加选、控制组、编队移动、队列移动/攻击；
- 伤害、冷却、摧毁、胜负、战斗日志和遭遇状态；
- 战术小地图、舰队列表、单位卡、性能仪表和高低特效切换；
- 程序化舰体材质、贴花、损伤层、推进焰、武器轨迹和命中反馈；
- 50、100、200 单位 deterministic 压力场景；
- 远景 LOD、阵营/舰种实例批次、12 个点光源预算和 256 对象特效池。

## 操作

- 左键单选，拖拽框选，Shift+左键加选/移除；
- 右键移动或攻击，Shift+右键追加队列；
- `Control+1` 至 `Control+9` 设置控制组，`1` 至 `9` 召回；
- `S` 停止，`P` 暂停/恢复，`R` 重置相机，`N` 重开；
- 滚轮缩放，中键拖拽平移，小地图点击/键盘移动战术焦点。

## 候选版验证

- `npm test`：2 个测试文件、9 项测试；
- `npm run typecheck`；
- `npm run build`；
- `npm run smoke -- https://rts-game-dev.rococo.dev`；
- 1280×720 固定 seed 普通遭遇和 200 单位压力回归；
- 390×844 移动视口压力场景回归；
- Chromium/WebGL + Apple M3 Max 上的选舰、暂停、特效切换和实例拾取。

200 单位实例化场景的记录值约为 34 draw calls、2.35 ms renderer CPU 提交时间；该指标不等同于 GPU 完成时间。

## 已知限制

- 舰船仍为程序化原型资产，缺少最终商业级模型、手绘/PBR 纹理和环境资产；
- 主 JavaScript bundle 约 608 kB，Vite 会报告超过 500 kB 的警告；
- 独立 Firefox、Safari、Windows/NVIDIA/AMD/Intel GPU 尚未验证；
- 200 单位是当前可选上限，继续扩大前需要延迟创建近景视觉、共享资源或空间分块实例化；
- 固定截图目前用于人工视觉回归，尚未加入自动像素差异阈值；
- 当前只提供随机遭遇，不包含战役、多人、完整经济或任务编辑器。

多环境验证恢复方式见 [deferred-compatibility.md](../deferred-compatibility.md)，详细性能数据和截图基线见 [2026-08-12 进度记录](../progress/2026-08-12.md)。

## 发布流程

候选版先提交到 `oc-workspace/rts-game`，再由隔离生产桥接目录创建 release 分支，同步到 `oWinnieo/rts-game` 并通过人工 PR 合并。内部发布脚本说明不进入仓库。
