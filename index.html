HOW TO PLAY

指挥蓝色玩家舰队，摧毁红色敌方舰队。按下面 5 个步骤操作，就能完成一局遭遇。

  1. SELECT / 选择左键点击蓝色舰船；拖拽框选多艘，Shift+左键追加选择。
  2. MOVE / 移动选中舰船后，在空白战场按鼠标右键移动。
  3. ATTACK / 攻击左键点击红色敌舰锁定目标，再按右键攻击；也可以直接右键敌舰。
  4. COMMAND / 指挥Shift+右键追加指令；S 停止，P 暂停；Ctrl+1 编组，1 召回。
  5. WIN / 获胜在左侧战斗日志观察命中和损失，消灭全部 HOSTILE 即可结束遭遇。
